## Инсайты и выводы

- **Telethon — это не Bot API.** MTProto-клиент (asyncio, чистый Python) даёт пользовательский доступ к Telegram: чтение своей истории, контактов, диалогов. Bot API — урезанный срез. Для автоматизации своего аккаунта — только Telethon/Pyrogram.

- **lang_code="ru" критичен для РФ.** Без `lang_code="ru"` + `system_lang_code="ru-RU"` код подтверждения не доходит на российские номера. С ними — приходит мгновенно.

- **Чёткая граница User vs Bot.** Пользователь не может кнопки (ни inline, ни reply). Бот через MTProto не может `get_dialogs()`, `iter_messages('me')`, писать другим ботам, инициировать диалог. Но может слушать `events.NewMessage` и отвечать.
