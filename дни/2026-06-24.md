## Инсайты и выводы

- annotation ≠ config. Метка `_switched_to_minimax_at` в джобе не меняет реальный model/provider. Джоба maxim-daily-backup 9 дней работала на DeepSeek, хотя метка утверждала MiniMax. Annotation — для аудита, config — для реальности

- Paused Adapter = silent failure. Gateway жив (pgrep), процесс работает, health-check SILENT, но Telegram не принимает сообщения 12+ часов. Нужна проверка `grep "paused after" gateway.log`, а не только `pgrep`

- TTS generation error → phantom MEDIA path → gateway silent block → пользователь не получает файл. 100% SILENT health-check маскируют проблему


## Трудности и решения

- Annotation ≠ Config: Верить меткам в JSON вместо реальных значений. Симптом: джоба работает не на той модели. Решение: сверять model/provider, не annotation

- Silent Health Check: Процесс жив → система ОК. Симптом: gateway жив, но Telegram не принимает. Решение: проверять функциональность, а не процесс
