- аудит 35 репозиториев deepseek-ai показал, что 77% из них — GPU-инфраструктура для тренировки на кластерах NVIDIA. Для практического использования на Mac полезны только awesome-списки (integration, agent) и OCR-модели

## Трудности и решения

- Рекомендовать инструмент на основе бенчмарков без проверки на реальных данных целевого языка (DeepSeek-OCR-2: 91% OmniDocBench, но 0% на русском)

- Угадывать параметры Gradio API вместо чтения `/config` (2 из 6 тестов провалены из-за неверных параметров Space)

- Использовать `huggingface_hub InferenceClient` для кастомных моделей с `trust_remote_code=True` — несовместим (StopIteration + TypeError)


## Рекомендации на будущее
